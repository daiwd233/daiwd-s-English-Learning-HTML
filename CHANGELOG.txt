# 更新记录 — 与原版差异

## 功能变化

| 项目 | 原版 | 新版 |
|------|------|------|
| 词库 | 仅 CET-6 (3991 词) | CET-4 (1877) + CET-6 (3991) + 考研英语 (1546) |
| 模块切换 | 无 | 头部 CET-4 / CET-6 / 考研英语 按钮切换 |
| 标题 | 固定显示 "CET-6" | 动态显示当前模块名称 |
| 数据存储 | 统一 `eng_learn_cet6` | 各模块独立: `eng_learn_cet4/6/ky` |
| 模块记忆 | 无 | 刷新后记住上次使用的模块 |

## 文件变动

- **新增** `cet4_words.js` — CET-4 词库
- **新增** `ky_words.js` — 考研英语词库
- **修改** `cet6_words.js` — 变量名从 `WORDS_DATA` 改为 `WORDS_DATA_CET6`
- **修改** `index.html` — 加入模块切换逻辑、3 词库加载、动态 localStorage
- **修复** `index.html` — `MODULES` 不再直接引用外部变量，改用 `loadVocab()` 惰性加载，防止词库 JS 缺失导致整页崩溃
